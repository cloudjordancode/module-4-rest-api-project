# Module 4: REST API Fundamentals — Starter Kit

## Quick Setup

### Option A: Clone with Git
```bash
git clone <repo-url>
cd module-04-rest-api-fundamentals
```

### Option B: Download ZIP (no Git required)
1. Go to this repo on GitHub
2. Click the green **Code** button → **Download ZIP**
3. Unzip and open the folder

---

### Shared steps (both options)

1. **Create a virtual environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate        # Mac/Linux
   venv\Scripts\activate           # Windows
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Start working:** Open any exercise folder and edit `starter.py` or `starter.md`.

> **Note:** All Python exercises in this module require an active virtual environment — they use the `requests` library which must be installed first.
